# Contributing

Contributions are welcome. This handbook improves when practitioners share what they have learned from real work.

---

## What makes a good contribution

- **Practical over theoretical.** Explain how something works in real analytics data science work, not just how it is defined.
- **Concise.** One clear example beats three vague ones.
- **Consistent format.** Follow the structure used in existing files: explanation → example → common mistakes → exercise.
- **Original writing.** Do not summarise blog posts or paste documentation. Add something that could not be found easily elsewhere.
- **No link dumps.** Add an external link only if the target is significantly better than a paragraph of explanation.

---

## How to contribute

1. Fork the repository
2. Create a branch: `git checkout -b add/topic-name`
3. Write or edit content following the existing format
4. Submit a pull request with a short description of what you added and why it improves the handbook

---

## Types of contributions

| Type | Examples |
|------|---------|
| New content | A missing topic, a new case study, an additional SQL pattern |
| Improvements | Clearer explanation, better example, corrected mistake |
| Templates | New checklist, analysis template, decision memo format |
| Exercises | Practice questions, mini-tasks, worked examples |
| Fixes | Typos, broken links, incorrect SQL or Python |

---

## What not to contribute

- Exhaustive reading lists or link collections — this is not an "awesome" list
- Vendor-specific content (documentation for a specific BI tool or cloud platform)
- Generic blog post summaries without original explanation
- Notebooks or code that require proprietary data or tools to run

---

## Format guide

Each content file should follow this structure:

```
# Topic name

## Why this matters
## Core concepts
## Practical example
## Common mistakes
## Exercises
```

Each folder README should follow the full format defined in the existing READMEs (Why this matters → What you need to know → Core concepts → Practical example → Common mistakes → Interview relevance → Exercises → Next folder).

---

## Questions

Open an issue if you are unsure whether a contribution fits, or want to discuss the direction of a section before writing it.
